How it works

An artist uploads a realistic drawing and the reference photo it was drawn from. The app flattens a phone photo of paper, then a critic agent compares the two using a small, read-only toolbox: zoom into grid cells, overlay a labeled grid, measure how far the drawing's outline is from the photo's after best-fit alignment, compare facial proportions from detected landmarks, and load topic lessons. It has eight tool calls, then must answer with two or three located, directional fixes.

When a revision is uploaded, a separate judge — which never sees the critic's reasoning — decides whether each fix landed. For proportion issues, confident measurement overrides the judge, and every disagreement is logged.

Everything is recorded in an append-only log. Offline, a single dreamer agent reads batches of sessions and proposes edits to the shared lessons as a pull request: strengthening what led to real fixes, rewriting what confused people, retiring what stopped working. Outcomes count far more than ratings, so the system learns to help rather than to please.

This site is generated by the same app and published to GitHub Pages; it has no backend.
